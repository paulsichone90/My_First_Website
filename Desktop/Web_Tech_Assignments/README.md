# Personal Portfolio Website

## About the Project

This is a personal portfolio website developed as part of the ICT251 Web Technologies Activity 3 at Mulungushi University.

The website presents my background, hobbies, learning plan, photographs, media, skills, and projects. It demonstrates the use of HTML, CSS, and JavaScript to build a responsive and interactive website.

## Features

* Semantic HTML structure and accessible navigation
* Responsive layout for desktop and mobile screens
* Light and dark theme switch
* Interactive photo gallery with previous and next controls
* Project and skills search with a reset option
* Contact form validation and local message preview
* Learning-plan table, photographs, video, and audio

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

* `index.html` — website structure and content
* `css/styles.css` — layout, styling, themes, and responsive design
* `js/script.js` — interactive features and form validation
* `images/` — website images
* `videos/` — video and audio assets

## Running the Project

Open `index.html` in a web browser, or run the project using a local development server.

## Contact Form Notice

The contact form is a browser-side demonstration. It validates input and displays a local preview; it does not send messages to a server.
